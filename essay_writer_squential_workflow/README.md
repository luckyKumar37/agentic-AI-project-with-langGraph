# Sequential Essay Writer

This example uses LangGraph to create an essay in two sequential LLM steps:

1. **Draft** — write a structured essay about the input topic.
2. **Revise** — improve the draft for accuracy, clarity, structure, grammar,
   depth, and conciseness.

The graph passes the topic and generated text through a shared state, then
prints the revised essay.

## Requirements and setup

Install the project dependencies from the repository root:

```powershell
python -m pip install -r requirements.txt
```

Set `GROQ_API_KEY` in the root `.env` file:

```dotenv
GROQ_API_KEY=your_groq_api_key
```

The script loads this value with `python-dotenv` and uses the Groq-compatible
`openai/gpt-oss-20b` model through `ChatGroq`.

## Run

From the repository root:

```powershell
python essay_writer_squential_workflow\Eassy_writer.py
```

The topic is currently set to `neural network` in the `app.invoke(...)` call at
the bottom of `Eassy_writer.py`. Change the `input_topic` value there to write
about another topic.

## Workflow state

The LangGraph state contains:

- `input_topic` — the essay subject.
- `first_draft` — the initial essay generated by the draft node.
- `final_essay` — the revised essay generated by the revision node.

Execution follows `START → first_draft → revise_draft → END`. Both generation
steps make an LLM API call, so a valid Groq API key and network access are
required.
